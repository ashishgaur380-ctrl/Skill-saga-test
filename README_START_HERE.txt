SKILL SAGA - SIMPLE APK BUILD PROJECT

This is the simplified project for building a test APK.
It removes the previous ZIP-extraction workflow.

The project itself must be uploaded to GitHub as folders/files.
The included .github/workflows/build-apk.yml builds app-debug.apk automatically.

Do not upload this ZIP as the only repository file; GitHub Actions needs the
actual project folders (app, .github, etc.) in the repository.
