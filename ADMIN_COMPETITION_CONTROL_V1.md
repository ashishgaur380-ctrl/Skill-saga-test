# Skill Saga — Admin Competition Control v1

Status: Development / test branch

Scope:
- Competition dashboard and status counts
- Create and edit competitions
- Competition type, class, subject and category
- Start/end schedule
- Duration, question count and entry coins
- Existing quiz ID references
- Draft / scheduled / published / unpublished / archived status
- Publication flag derived from status

Workflow:
Stable → Backup → Modify → Test → Approve → New Stable

This module is intentionally separate from Play Control and does not alter learner UI or competition-result records.
