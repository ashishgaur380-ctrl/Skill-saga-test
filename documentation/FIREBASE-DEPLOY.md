# Firebase Deployment

Development project: `skill-saga-2`

## Safe deployment order

1. Authenticate Firebase CLI.
2. Confirm the active project is `skill-saga-2`.
3. Deploy Firestore rules.
4. Deploy backend functions when implemented.
5. Verify authentication and Firestore from the Admin application.

## Safety

Do not deploy to a production project from this repository.
Do not commit credentials.
