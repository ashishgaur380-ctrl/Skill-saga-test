## Suggested academic class progression

- Current class: free/unlocked
- ±1 class: 500 XP + 50 Coins
- ±2 classes: 1000 XP + 100 Coins
- ±3 classes: 2000 XP + 200 Coins
- Higher/advanced access: progressive requirements configured by Admin

XP is a threshold; coins are spendable.

## Play activities

- Daily Quiz
- Quick Practice
- Topic Practice
- Mixed Quiz
- Assigned Quizzes
- Puzzles: Logic, Number, Visual Reasoning, Word, etc.

Play remains focused on quizzes, puzzles, XP, coins and progression. Competitions belong in Compete.
